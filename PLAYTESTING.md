# Playtesting — Quest for the Claw

This repo uses GitHub Issues as the “test team” intake.

## Quick start

1. Open the latest build (see README).
2. Play until you win or get stuck.
3. File issues:
   - **Bug**: use **🐛 Bug report** (include screen number + repro steps)
   - **Feedback**: use **🎮 Playtest session report**

## What we want testers to look for

**Blockers (highest priority)**
- Any screen that’s impossible to clear
- Falling through platforms
- Vine grab/drop not working
- Hazards that can’t be avoided
- Soft locks (stuck in geometry)

**Gameplay feel**
- Jump distance/height (is it fair?)
- Movement friction / acceleration
- Checkpoint location & usefulness

## Screen numbering

We refer to “screen 1, 2, 3…” from left to right.

Tip: enable debug (press **D**) to see screen index + player coordinates.
